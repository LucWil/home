# Les Willys — l'app web (artifact claude.ai)

`les-willys.html` est une copie du code de l'artifact **Les Willys**, la version web que la famille
utilise : https://claude.ai/artifact/F9oX5r1Bahywdn7R5bx8jw

- **La version de référence est celle en ligne.** Ce fichier sert à garder l'historique des versions
  et à travailler sur le code depuis le Mac. Le modifier ici ne change pas la page en ligne.
- **Pour faire évoluer l'app web**, demande à Claude (claude.ai/code ou Claude Code) en lui donnant le
  lien de l'artifact : il lit la version en ligne, la modifie et la republie. Demande-lui ensuite de
  mettre à jour cette copie pour garder la trace.
- **Les données de la famille** (calendrier, stock, recettes, photos, IBAN…) ne sont pas dans ce
  fichier : elles vivent dans la base de l'artifact. Les sauvegardes « Données » du Coffre des Willys
  les contiennent ; ne les ajoute jamais au dépôt.

Copie du 4 novembre 2026 (version en ligne 1793818319-de6d).
